# 主张-证据对照表 · v18 / C4′（Claim–Evidence Map）

> 本表逐条绑定：原文位置 → 支撑脚本 → 工作簿表格 → 统计口径 → 证据强度。
> 「原文位置」一律记节号与式号（如 §3.1、式(2)），可直接在 `paper/` 下的 PDF 中核对；
> 「工作簿表格」一律记 `outputs/*.xlsx` 的具体表名与行，可逐个数字回查。
>
> **强度定义**：`strong` = 闭式推导或不含自由参数的点预测且有实测对照；
> `moderate` = 有实测与区间但为样本内 / 单批次；`weak` = 只有点估计、未设通过阈值；
> `withdrawn` = 曾主张、经对照检验后在正文撤回。
